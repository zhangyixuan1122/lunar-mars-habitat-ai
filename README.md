# Lunar / Mars Habitat AI

[张译轩个人官网](https://zhangyixuan.xyz) · [核心项目档案](https://zhangyixuan.xyz/projects/)

## 项目背景

本仓库用于说明《面向月球/火星基地的AI资源管家系统》的公开场景：在资源受限的深空基地中，关注电力、水、氧气、温湿度与光照等状态，并讨论风险判断与调度建议的可能路径。
